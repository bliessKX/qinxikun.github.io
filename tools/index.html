工具

日常随手用的小工具，每个工具一个独立页面，互不干扰、互不掺杂。 点进任意一张卡片，进入的就是它自己的专属页面。

  • JSON 解析与格式化

    文本处理

    把 JSON 文本整理成能读的格式，或反过来压缩成一行。附带校验、修复、键排序与 Unicode 转义。

    • 格式化 / 压缩 / 键名排序
    • 脏 JSON 自动修复（去尾逗号、补引号）
    • 树形视图折叠展开
    • Unicode 转义与反转义
    • 内置 5 档示例数据，打开即用
    打开工具 → tools/json.html

  • 常用命令速查

    开发运维

    Git、SVN、Linux、Docker、Maven、MySQL、Redis、Nginx、Java 九类常用命令，随手查、随手复制。

    • 9 大分类 · 119 条命令
    • 按分类切换，关键词搜索
    • 单条复制，或整组复制成带注释脚本
    • EXPLAIN 等命令附返回列逐项释义
    打开工具 → tools/commands.html

  • 今天吃什么 · 转盘

    生活

    按当前时间自动判断早、中、晚餐，再从中餐、西餐、马来西亚餐里转出一个答案，替你解决选择困难。

    • 按时段自动匹配三餐
    • 8 种菜系可切换
    • 转盘动画揭晓结果
    • 候选菜品可自行增删
    打开工具 → tools/what-to-eat.html

各页独立，互不影响

每个工具跑在自己的页面里，脚本互不干扰。可以单独收藏某页地址长期使用，不必每次都从这里进。

不用注册、不上传

全部在浏览器本地运行，数据不离开你的电脑。JSON 内容不会存到任何服务器，关掉页面就清空。

随时接着改

工具是持续在长的。新增功能会同步更新到对应页面，也会记进仓库的变更记录里。

每个工具都是独立页面 —— 也可以直接收藏某一页的地址，单独使用，不必经过目录。 ← 回到笔记首页
