卷 四  ·  文 章

微信小程序多设备登录：多端共存、同端互斥完整方案

鉴权之道　·　2026-10-13　·　十篇同此版式

场景是同一用户要在 iPad、手机、电脑三端小程序同时在线：多端共存，同类型设备后登录踢掉先登录的。技术栈 Spring Security + JWT + Redis，前提是把设备码 deviceType 写进 JWT payload。

小程序端用 wx.getDeviceInfo 拿 platform 与 model，映射成 IPHONE、IPAD、PC。有个边界要注意：platform 为 ios 时 iPhone 和 iPad 不分家，只能靠 model 判断；新机型 model 返回 unknown 会回落到 IPHONE，小概率误踢。

双 Token 方案里 Redis 只存 RefreshToken，按 login:IPHONE:123 这样的 key 分端覆盖。同端再登录会覆盖旧的 RefreshToken，但旧设备还能撑到 AccessToken 过期，最长三十分钟，这就是俗称的假在线。

单 Token 把 Token 本身存 Redis、每次请求比对，覆盖即踢，下一次请求就 401，代价是 Redis 成了强依赖。选型结论：要瞬间踢人用单 Token，要高安全能接受延迟用双 Token，两者都要就双 Token 加 WebSocket 推送。
