# NICE.BLOG

个人博客主页，主要分享在日常开发中遇到的问题和解决方案。

## 2.0 — Interactive Developer Platform（2026-11-10）

React 18 + TypeScript + Vite 构建的交互式开发者平台，纯静态部署，零后端、零追踪。

- **Home** `#/` — Canvas 粒子技术网络（视差/悬停/点击进图谱），精选内容
- **Blog** `#/blog` — 11 篇真实项目笔记，搜索 + 详情 + 旧 hash 兼容（`#/3` 自动落对应笔记）
- **Tools** `#/tools` — 工具中心，收藏/最近使用（localStorage）；旧工具页（`tools/*.html`）原样保留互跳
- **Knowledge** `#/knowledge` — 自研 Canvas 力导向知识图谱：23 技术 + 11 文章 + 3 工具，搜索/筛选/详情/拖拽
- **Lab** `#/lab` — JSON 工作台 / 正则测试器 / 时间戳·Base64（全部本机计算）
- **Projects / About** — 真实脱敏项目与介绍

### 开发

```bash
cd app
npm install
npm run dev      # 本地开发
npm run build    # 构建到 app/dist（public/ 原样透传旧站面）
```

### 部署

push `main` → GitHub Actions 构建（含旧站面守卫：CNAME/404/旧工具页缺失即失败）→ Pages 发布。
首次启用需在仓库 Settings → Pages 把 Source 切到 **GitHub Actions**。

### 留言板（可选）

`#/guestbook` 由 GitHub Discussions + Giscus 承载，无需自建服务器或数据库。线上地址：`https://qxkk.dpdns.org/2.0/#/guestbook`（2.0 主站挂在 `/2.0/` 下）。

配置分两处：

| 文件 | 用途 | 进仓库 |
|---|---|---|
| `app/.env` | 线上默认配置，GitHub Actions 构建时读取 | ✅ |
| `app/.env.local` | 本地覆盖（优先级更高），可选 | ❌ |

启用步骤：

1. 仓库 Settings → 开启 **Discussions**，安装 [Giscus App](https://github.com/apps/giscus) 并授权到本仓库（改完记得点「保存」）。
2. 到 [giscus.app](https://giscus.app) 填仓库 `bliessKX/qinxikun.github.io`，在「Discussion 分类」下拉选一个分类（推荐 **Announcements** 类型：仅维护者/giscus 能建帖，访客仍可回复），复制生成的 `categoryId` 与实际分类名。
3. 把 `categoryId` / `category` 填进 `app/.env`。`repo` 与 `repoId` 已预填。
4. `npm run build` 本地验证 → push `main`，Actions 自动部署。

> 这 4 个值在 Giscus 前端脚本里本来就是明文，不是密钥，可以提交。若只填 `.env.local`，Actions 读不到，线上会停在「配置引导」页。

**关闭 / 兜底**：把 `app/.env` 的 `VITE_GUESTBOOK_ENABLED` 改成 `off` 再 push，导航、footer 入口与第三方脚本一起消失，站点回到纯静态版本；留言数据留在 GitHub Discussions，不会丢。

## 1.0 旧站（仍完整保留）

- **笔记**：收录 11 篇技术博文，涵盖鉴权、JDK 新特性、分页优化、MySQL 调优、Agent 编排与智能体选型等方向。
- **工具**：`tools/`，日常用的小工具集合。**每个工具一个独立页面**，互不掺杂，可单独收藏地址直接使用。
  - `tools/index.html` —— 工具目录页。一张卡片一个工具，写清它能做什么，点进去就是该工具自己的页面；各工具页顶栏统一带「全部工具」入口，可随时互跳。
  - `tools/json.html` —— JSON 解析与格式化，支持格式化、校验、修复、压缩、键排序、转义、树形折叠、复制与下载；每次操作都有浮层提示，全屏模式下顶部常驻退出入口；内置 5 档示例数据（博客配置 / 接口响应 / 数组列表 / 脏数据 / Unicode 转义），打开即有内容可看。
  - `tools/commands.html` —— 常用命令速查，Git / SVN / Linux / Docker / Maven / MySQL / Redis / Nginx / Java 共 9 类 119 条命令，支持按分类切换、关键词搜索，单条复制或整组复制成带注释的脚本；MySQL 的 `SHOW FULL PROCESSLIST` 与 `EXPLAIN` 附输出列逐项释义。
  - `tools/what-to-eat.html` —— 一个「今天吃什么」的选餐转盘，按当前时段自动推荐早/中/晚餐，支持中餐、西餐、马来西亚餐、日料、韩餐、泰餐、印度菜等菜系切换。
- **卷册**：`ink/`，水墨风格的设计稿原型（多卷级联目录）。

- 命令速查补充 MySQL 常用排查命令：`SHOW FULL PROCESSLIST`（查看正在执行的 SQL）、`EXPLAIN`（分析执行计划）、`EXPLAIN ANALYZE`（8.0.18+ 实际执行并计时），并附上每个返回列的含义对照 —— 如 `type` 的访问类型性能排序、`key` 为空即未走索引、`Extra` 里 `Using index/filesort/temporary` 各自的含义；速查区支持「字段说明」卡片，整组复制时注释一并带走。
