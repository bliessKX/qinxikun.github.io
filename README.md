# NICE.BLOG

个人博客主页，主要分享在日常开发中遇到的问题和解决方案。

- **笔记**：收录 10 篇技术博文，涵盖鉴权、JDK 新特性、分页优化、MySQL 调优、Agent 编排等方向。
- **转盘**：`what-to-eat.html`，一个「今天吃什么」的选餐转盘，按当前时段自动推荐早/中/晚餐，支持中餐、西餐、马来西亚餐、日料、韩餐、泰餐、印度菜等菜系切换。
- **卷册**：`ink/`，水墨风格的设计稿原型（多卷级联目录）。

## 功能变更

### 2026年11月10日

- 新增食品转盘，解决你的选择困难症 —— 打开网址直接转，按当前时间自动判断早餐 / 午餐 / 晚餐，可切换中外各类菜系，转完揭晓今天吃啥。
