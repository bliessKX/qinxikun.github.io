# NICE.BLOG

个人博客主页，主要分享在日常开发中遇到的问题和解决方案。

- **笔记**：收录 11 篇技术博文，涵盖鉴权、JDK 新特性、分页优化、MySQL 调优、Agent 编排与智能体选型等方向。
- **工具**：`tools/`，日常用的小工具集合。**每个工具一个独立页面**，互不掺杂，可单独收藏地址直接使用。
  - `tools/index.html` —— 工具目录页。一张卡片一个工具，写清它能做什么，点进去就是该工具自己的页面；各工具页顶栏统一带「全部工具」入口，可随时互跳。
  - `tools/json.html` —— JSON 解析与格式化，支持格式化、校验、修复、压缩、键排序、转义、树形折叠、复制与下载；每次操作都有浮层提示，全屏模式下顶部常驻退出入口；内置 5 档示例数据（博客配置 / 接口响应 / 数组列表 / 脏数据 / Unicode 转义），打开即有内容可看。
  - `tools/commands.html` —— 常用命令速查，Git / SVN / Linux / Docker / Maven / MySQL / Redis / Nginx / Java 共 9 类 119 条命令，支持按分类切换、关键词搜索，单条复制或整组复制成带注释的脚本；MySQL 的 `SHOW FULL PROCESSLIST` 与 `EXPLAIN` 附输出列逐项释义。
  - `tools/what-to-eat.html` —— 一个「今天吃什么」的选餐转盘，按当前时段自动推荐早/中/晚餐，支持中餐、西餐、马来西亚餐、日料、韩餐、泰餐、印度菜等菜系切换。
- **卷册**：`ink/`，水墨风格的设计稿原型（多卷级联目录）。

## 功能变更

### 2026年11月10日

- 新增笔记《Java 后端做 Agent 智能体选型实战：Spring AI Alibaba 与 Spring AI + LangChain4j/LangGraph 对比》—— 从 Java 微服务视角对比两条智能体路线，涵盖企业微信群聊助手（Spring AI Alibaba 快速落地）与道路交通桥梁查询智能体（Spring AI + LangGraph 复杂编排）两个真实场景，以及身份越权、敏感数据脱敏、数据时效性、工具降级等落地坑位。笔记总数增至 11 篇。
- 工具全部拆成独立页面并统一归到 `tools/` 目录：新增工具目录页 `tools/index.html`，一张卡片对应一个工具，各自独立成页、互不掺杂；「今天吃什么」转盘从根目录移入 `tools/what-to-eat.html`，路径与命名跟其他工具对齐。三个工具页顶栏统一为同一套导航（含「全部工具」入口），窄屏自动收敛为「全部工具 + 返回主页」两枚，避免挤成两行。
- 「常用命令速查」从 JSON 工具页拆出为独立页面 `tools/commands.html` —— JSON 解析与命令查询本就是两件事，合并在一页既挤又不好维护；新页有独立标题区、吸顶分类栏与搜索框，命令不再被限制在固定高度的滚动框里；两个工具页顶栏互加跳转入口。
- 命令速查补充 MySQL 常用排查命令：`SHOW FULL PROCESSLIST`（查看正在执行的 SQL）、`EXPLAIN`（分析执行计划）、`EXPLAIN ANALYZE`（8.0.18+ 实际执行并计时），并附上每个返回列的含义对照 —— 如 `type` 的访问类型性能排序、`key` 为空即未走索引、`Extra` 里 `Using index/filesort/temporary` 各自的含义；速查区支持「字段说明」卡片，整组复制时注释一并带走。
- JSON 工具新增「常用命令速查」目录（工具栏下方）：收录 Git / SVN / Linux / Docker / Maven / MySQL / Redis / Nginx / Java 共 9 类 119 条常用命令，支持分类切换与关键词搜索；每条命令可一键复制，也可按分组整段复制成带注释的 shell 脚本，复制后有浮层提示与按钮态反馈。
- 修复 JSON 工具「示例」与「打开文件」按钮点击无响应的问题（事件委托此前只绑定在工具栏内，面板头按钮不在作用域中）；新增「示例」下拉菜单，提供博客配置 / 接口响应 / 数组列表 / 脏数据 / Unicode 转义 5 档示例数据。
- JSON 工具首屏预置示例数据，打开即见输入与输出内容，不再是两个空白面板。
- 修复 JSON 工具在文本视图下「选中所有键 / 值」无标记的问题（树形 DOM 尚未生成）。
- JSON 工具补充操作反馈：复制成功 / 下载完成 / 格式化校验等操作弹出右下角浮层提示，「复制」按钮变为「已复制 ✓」绿色态；全屏时顶部出现浮层条，按钮文案切换为「退出全屏」，并提供明确的退出入口（Esc 或点「退出全屏」）。
- 主页改为三栏布局：「今天吃什么 · 转盘」回到站名下方原位，「工具」目录移至右侧独立成栏。
- 新增「工具」一级目录（位于笔记下方），作为站内工具列表；侧栏笔记列表改为可滚动区，工具与背景音乐入口固定在首屏可见。
- 新增 JSON 解析与格式化工具（`tools/json.html`）：格式化、校验、修复、压缩、键排序、转义、树形折叠、复制、下载、全屏、折叠、清空，纯前端运行、内容不出浏览器。
- 新增食品转盘，解决你的选择困难症 —— 打开网址直接转，按当前时间自动判断早餐 / 午餐 / 晚餐，可切换中外各类菜系，转完揭晓今天吃啥。
- 新增「笔记」一级目录，左侧固定目录挂 10 条 CSDN 博文，点击右侧即展开正文与原文链接。
- 博客主页改版为文档站版式，移除毛玻璃、胶囊按钮等模板化元素。
- 水墨卷册页统一品牌名，全站清除个人隐私信息。
